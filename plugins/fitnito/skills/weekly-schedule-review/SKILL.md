# Weekly schedule review

## When to use

- "What's on the schedule this week?"
- "Which classes are full, and which are empty?"
- "Give me a summary of next week."

## Steps

1. If the login can open more than one gym, ask which gym. Don't pick one.
2. Get the schedule for the week they asked about. If they didn't say, use the current week, Monday to Sunday, in the gym's own time zone.
3. Summarize by day. For each class, give the name, the time, the coach if there is one, and how many are booked out of the capacity. If a weekly class has no booking count yet, list it with its time only.
4. Point out what needs a look: full classes, classes with no bookings, classes with no coach, and classes that overlap at the same location.
5. Offer next steps, like adding a class, moving someone, or checking a member. Don't make any change until they ask for it.

## Keep in mind

- This is a read-only review. Nothing is created, changed, or sent.
- Keep it short. Use a table or a list per day, not paragraphs.
- Say "no classes" for an empty day instead of skipping it.
