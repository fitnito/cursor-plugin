# Set up a new gym

## When to use

- "I just signed up. Help me set up my gym."
- "Add my location, my classes, and my prices."

## Order

Work in this order, because each step needs the one before it:

1. **Location.** Ask for the name and address of each place classes happen.
2. **Programs.** These are the types of class, like Yoga, Training, or Kids BJJ. Ask for the names and a one-line description of each.
3. **Pass types.** A pass decides which programs a member can book, like "All access" or "Yoga only". Ask for the name and which programs it covers.
4. **Plans and packs.** These are what members buy, like a monthly membership or a 10-visit pack. Ask for the name, the price, and which pass it gives. For a pack, also ask how many visits it has. If Fitnito Payments isn't set up yet, say the plans and packs are saved and will be ready to sell once Fitnito Payments is set up.
5. **Schedule.** Ask for the weekly timetable: the day, the start and end time, the program, the location, the coach, and the capacity. Ask when the timetable starts.
6. **Wrap up.** Show the week's schedule back to them. Point them to their booking site so they can see what members will see.

## Steps for each item

- Collect what you need for one step, then show it back as a short list and ask "Look right?" before you create it.
- Create it, then confirm what was made.
- If something already exists with the same name, ask before you add a second one.

## Keep in mind

- Ask about weekly classes and one-off classes separately. Don't turn a one-off into a weekly series.
- Use the gym's own time zone for every time.
- Don't invite staff or members, and don't send any email, as part of setup unless they ask. See the ask-before-emailing skill.
